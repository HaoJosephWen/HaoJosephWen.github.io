项目经历

手持打印PDA（2025.03 - 至今）

工作内容： 负责打印机芯控制模块架构设计与实时性优化。

技术难点：

  • 步进电机转速与热敏头加热时序需微秒级同步，否则会导致图像错位或加热不均
  • SOC 串口持续高速推流，需保证接收零丢包同时不阻塞打印任务

解决方案：

  • 基于 uCOS 创建”数据接收”与”打印控制”双任务架构，通过消息队列解耦
  • 设计 DMA + 乒乓双缓冲机制，双缓存区交替接收，实现数据”零拷贝”流转，提升串口带宽利用率
  • 将图像解析、电机步进、加热控制重构为三级流水线并行处理，降低单行打印耗时
  • 热敏头加热采用 TIM + PWM 微秒级脉宽调制，配合 ADC 实时温控动态调整占空比，防止过热烧头

井盖智能监测设备（2024.07 - 2024.12）

工作内容： 设计井盖状态（丢失/破损/移位/浸水/甲烷）多维度感知与 NB-IoT 远程上报方案，构建低功耗架构实现电池续航 ≥ 3 年。

技术难点：

  • 井下 NB-IoT 信号衰减严重，数据包容易丢失
  • 3 年续航要求 μA 级平均电流，与告警实时响应需求冲突

解决方案：

  • 设计间歇唤醒架构，RTC 定时 1 小时唤醒上报心跳数据，异常中断触发即时告警上报
  • 传感器分组供电，仅检测周期内上电
  • NB-IoT 模组启用 PSM 深度休眠与 eDRX 扩展不连续接收，空闲时电流 < 5μA
  • 数据包采用 CoAP 紧凑二进制编码，缩短发射时长
  • 建立三级缓存机制，网络异常时本地存储待恢复后补发，避免无效重传功耗
  • 整机平均电流控制在 25μA 以内，实现 3 年续航目标

1.38kW 电源控制系统（2025.04 - 2025.05）

工作内容： 基于 GD32E11x 设计电源控制板，支持电压电流可调，具备上电时序管理及过温、短路、欠压保护。

技术难点：

  • 交流输入为工频正弦信号，需实时计算真有效值作为上电时序与保护的判据，对计算精度和响应速度要求较高
  • 多级上电时序涉及继电器、PFC、DCDC 等多环节严格先后依赖，任一环节异常均可能导致硬件损坏
  • 短路保护需准确区分瞬态负载跳变与真实短路，避免误触发导致频繁停机，同时响应迟滞又可能损坏功率器件

解决方案：

  • 交流有效值采用 DMA + ADC 连续采样，400ms 窗口内累加平方求和开根号计算 RMS，既适用于正弦波也适应畸变波形，确保计算精度
  • 上电时序采用有限状态机驱动（INIT → 输入检测 → PFC 启动 → DCDC 启动 → 运行 → 故障），每级设置超时计数器与条件回退，输入欠压时自动关断并支持条件恢复，确保时序严格可控
  • 短路保护采用 5 条件联合判断加连续 2 次确认防抖消除瞬态干扰，3 次短路锁定需掉电复位方可恢复防止反复短路损坏硬件，5 秒延时重试给予故障消除窗口实现安全恢复

多源补光灯（2025.08 - 2026.01）

工作内容： 设计多源补光灯控制系统，实现气体/LED 多光源协同控制、7 级亮度识别、多重安全保护。

技术难点：

  • 多光源独立中断驱动存在输出冲突与互斥风险
  • 7 级亮度模式需微秒级周期识别与连续防抖
  • 裸机环境下多任务调度与多维度安全保护逻辑复杂

解决方案：

  • 采用中断触发方式分别驱动三种光源，建立光源优先级仲裁机制，防止多灯同时输出造成冲突
  • 利用定时器精确测量输入控制信号的周期频率，依据不同频率自动匹配并切换对应的亮度工作模式，通过多次采样实现防抖，避免模式误判，自动交替高亮与低亮状态以增强补光对比度
  • 构建过流、过压、过温、频率异常及计数降功率等多重安全保护，防止设备过载损坏，并设置持续正常判定机制避免保护误退出
  • 通过 DAC 转换实现亮度精细调节
