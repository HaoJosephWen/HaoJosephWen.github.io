【技术排障】GD32E11x PA15 引脚 PWM 输出失败问题分析：JTAG 调试接口引脚冲突

发表于 2026-06-27 分类于 嵌入式开发

在使用 GD32E11x 系列单片机的 PA15 引脚作为定时器输出通道输出 PWM 时，发现 PWM 无法正常输出。查阅资料后发现，PA15 引脚在复位后默认并非普通 GPIO，而是被 JTAG 调试接口占用。

一、问题描述

使用 GD32E11x 系列单片机的 PA15 引脚作为定时器输出通道输出 PWM 时，发现 PWM 无法正常输出。

二、PA15 引脚默认功能

GD32E11x 系列单片机在复位后，PA15 引脚默认被分配为 JTAG 调试接口的 JTDI 信号，属于调试功能引脚，无法直接作为 GPIO 或外设复用功能使用。

在默认状态下，这 5 个引脚均被调试接口占用，用户无法将其作为普通 GPIO 或外设复用功能使用。

三、问题原因

当用户尝试将 PA15 配置为定时器的 PWM 输出通道时，由于 JTAG 接口仍处于使能状态，PA15 的功能被 JTDI 信号锁定，导致 GPIO 复用配置无法生效，PWM 信号自然无法输出。

四、解决方案

GD32E11x 提供了灵活的调试接口重映射机制。要释放 PA15 引脚，需要关闭 JTAG-DP，仅保留 SW-DP，即只保留 SWD 调试方式（PA13、PA14），释放 PA15、PB3、PB4 供用户使用。
