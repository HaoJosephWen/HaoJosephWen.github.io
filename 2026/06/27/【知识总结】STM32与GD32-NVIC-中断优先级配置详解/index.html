【知识总结】STM32与GD32 NVIC 中断优先级配置详解

发表于 2026-06-27 分类于 嵌入式开发

本文结合书籍《ARM Cortex-M3/M4 权威指南》和GD32与STM32的用户手册，对NVIC中断优先级配置进行详细讲解。

1. 优先级分组与优先级

优先级分组将中断优先级分为抢占优先级和响应优先级：

  • 抢占优先级：决定了中断是否能打断正在执行的较低优先级中断或任务。具有更高抢占优先级的中断可以中断当前正在执行的较低优先级中断或任务。
  • 响应优先级：在相同抢占优先级的中断或任务之间，响应优先级决定了中断或任务的执行顺序，确保了任务调度的公平性和确定性。

2. 设置优先级分组

操作方式 说明
CMSIS 函数 NVIC_SetPriorityGrouping()
操作寄存器 SCB->AIRCR（Application Interrupt and Reset Control Register）
操作位段 PRIGROUP（位 [10:8]）

注意：写入此寄存器需要特殊流程（必须先写入 0x5FA 到 VECTKEY 位段），否则写入无效。CMSIS 函数内部自动处理了这个”钥匙”操作。

3. 设置具体优先级

操作方式 说明
CMSIS 函数 NVIC_SetPriority(IRQn, priority)
操作寄存器 动态决定，取决于中断号（IRQn）是正数还是负数

情况 A：内核异常（IRQn < 0）

例如：SysTick_IRQn (-1)、PendSV_IRQn (-2)、SVCall_IRQn (-5)

  • 操作寄存器：SCB->SHP[]（System Handler Priority Registers）

情况 B：外部中断（IRQn >= 0）

例如：USART0_IRQn、EXTI0_IRQn

  • 操作寄存器：NVIC->IP[]（Interrupt Priority Registers）

4. 示例：STM32L431 优先级设置

以 STM32L431 为例，优先级寄存器有效宽度为 4，故存在 16 个可编程优先级，有 5 种优先级分组情况：

示例：若设置优先级分组为 NVIC_PRIORITYGROUP_2，设置某中断的优先级为 5（0101），则表示：

  • 抢占优先级 = 1
  • 响应优先级 = 1

5. 厂商函数差异

GD 系列

注意：只能配置外设中断，不能配置如 SysTick_IRQn 的系统中断。

ST 系列

说明：

  • ST 未提供封装的中断配置函数，可直接使用 CMSIS 函数。
  • __NVIC_SetPriority 可配置系统中断和外设中断，
  • __NVIC_EnableIRQ 的 IRQn 不能为负数。

6. Keil 调试中 Priority 列含义

在 Keil 的 Priority 列中，如果看到 A = B s C 的格式：

字段 含义
A 优先级寄存器值
B 抢占优先级
C 子优先级（需根据优先级寄存器有效宽度换算真实值）

示例：16 = 2 s 1 表示抢占优先级为 2，子优先级为 1（16 << 4，STM32L431 优先级寄存器有效宽度为 4）。
